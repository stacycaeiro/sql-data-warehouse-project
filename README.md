# Data Warehouse Project 

#### Objective 
Develop a data warehouse using SQL Server to organize sales data to use for analytics, reporting, and decision-making. 

#### Specifications 
- **Data Sources**: Import data from ERP and CRM, given as CSV files
- **Data Quality**: Clean data to prepare for analysis
- **Integration**: Combine data sources into a singular data model for user-friendly analytical queries
- **Scope**: Focus on most recent dataset, no historization
- **Documentation**: Provide clear documentation that is understandable for analytics team and business stakeholders
